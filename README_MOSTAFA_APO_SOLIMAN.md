# دليل المطوّر — مصطفى أبو سليمان

الدليل ده بيشرح المشروع من جوّه: إزاي بيشتغل، فين كل حاجة، وإزاي تصونه وتعدّل عليه من غير ما تكسره.

## 1) الصورة الكبيرة
```
المتصفح (client/js)  ──fetch + X-CSRF-Token──▶  Express (server/app.js)
                                                   │ helmet + CSP → cookies → attachUser → csrfProtect
                                                   ├─ /api/auth/*    routes/auth.js     (الدخول)
                                                   ├─ /api/admin/*   routes/admin.js    (المشرف فقط)
                                                   └─ /api/*         routes/student.js  (المواد والملفات)
                                                          │
                                                   repo.js  ◀── كل الـ SQL هنا بس
                                                          │
                                                   SQLite: storage/study.db     الملفات: storage/uploads
```
- **الـ Frontend** عبارة عن صفحة واحدة (SPA). `main.js` فيه الـ router، `views.js` شاشات الطالب، `admin.js` لوحة المشرف، `core.js` أدوات مشتركة (API, أيقونات, أنيميشن)، `i18n.js` كل النصوص عربي/إنجليزي.
- **الألوان والتصميم** كلها متغيّرات CSS في `client/src/styles.css` (أول الملف). غيّر لون واحد هناك يتغير في كل الموقع.

## 2) رحلة تسجيل الدخول (أهم حاجة تفهمها)
1. الصفحة بتطلب `/api/csrf` وتاخد توكن (كوكي + قيمة تتبعت في الهيدر مع أي POST).
2. **الاسم + الكود** → `POST /api/auth/login` → `checkRoster()` في `routes/auth.js`:
   قفل تصاعدي (5 محاولات غلط لنفس الكود = دقيقة، بعدها 2، 4، … لحد ساعة) ← بنجيب الطالب من الجدول ← `namesMatch()` في `lib/arabic.js` بيقارن بعد التطبيع ← لو نجح `startSession()` في `middleware.js` بيعمل كوكي `sid` عشوائي (بنخزّن الـ SHA-256 بتاعه بس) وبيلغي الجلسة القديمة اللي جاية مع نفس المتصفح (باقي أجهزة الطالب ما بتتأثرش، و«خروج من كل الأجهزة» بيلغيها كلها).
3. **Google** → المتصفح بيبعت `credential` ← السيرفر بيتحقق منه (التوقيع والـ audience والـ issuer والانتهاء وإن الإيميل موثّق). لو الإيميل مش مربوط: ما فيش جلسة، بنرجّع توكن ربط لـ 10 دقايق، والطالب لازم يكتب اسمه وكوده مرة واحدة.
4. **المشرف** → `/api/auth/admin` (إيميل + كلمة سر argon2 + اختياري 2FA) وله حدود أشد (3 محاولات).
5. كل نجاح أو فشل بيتسجّل في `activity_logs` (الاسم، الكود، الإيميل، الطريقة، IP، المتصفح، الوقت) وبيتبعت لحظياً للوحة المشرف عن طريق SSE (`bus` في `app.js`).

## 3) إزاي تعمل الحاجات الشائعة
| عايز | اعمل |
|---|---|
| تغيّر اسم دكتور/معيد/مادة، أو اسم المادة الثامنة | لوحة المشرف ← المحتوى ← «تعديل المادة» (من غير كود) |
| ترفع محاضرة/سكشن/تاسك/ملف | لوحة المشرف ← المحتوى. الملفات: اسحبها على المربع. الأنواع المسموحة: pdf, pptx, docx, xlsx, zip, png, jpg/jpeg, mp4, txt, ipynb |
| توقّف طالب أو تفك ربط Google | لوحة المشرف ← الطلاب |
| تضيف طلاب جداد (ترم جديد) | حط الكشف الجديد، شغّل `npm run extract -- كشف.pdf` ثم `npm run seed`. الـ seed آمن: بيحدّث الأسماء وما بيمسحش الإيميلات المربوطة ولا تعديلاتك على المواد |
| تغيّر كلمة سر المشرف | احذف صف الأدمن (`sqlite3 storage/study.db "DELETE FROM admins"`)، غيّر `ADMIN_PASSWORD` في `.env`، شغّل `npm run seed` |
| تفعّل 2FA | حط `ADMIN_TOTP_SECRET` (base32) في `.env` وأضفه لتطبيق المصادقة، وأعد إنشاء الأدمن بنفس الخطوة اللي فوق |
| تغيّر مدة حفظ السجلات | `LOG_RETENTION_MONTHS` — بيتم مسح القديم تلقائياً كل يوم |
| تضيف لغة/نص | `client/js/i18n.js` (كل نص له مفتاح عربي وإنجليزي) |
| تعدّل التصميم ثم تبنيه | عدّل `client/src/styles.css` أو `client/js/*.js` ثم `npm run build` |
| تضيف جدول أو عمود | أضف migration جديد في آخر مصفوفة `MIGRATIONS` في `server/db.js` (ما تعدّلش القديم) ثم استخدمه في `repo.js` |

## 4) الصيانة
- **النسخ الاحتياطي**: انسخ فولدر `storage/` كله (قاعدة البيانات + الملفات) يومياً.
- **الأسرار**: `SESSION_SECRET` لو اتغيّر كل الجلسات هتتلغي (طبيعي). ما ترفعش `.env` على Git أبداً.
- **السجلات**: pino بتكتب JSON على الـ stdout (الكوكيز والتوكنات بتتشال منها).
- **لو طالب نسي اسمه الرباعي**: افتح «الطلاب» وابحث بالكود وشوف الاسم المسجّل، أو ابحث بجزء من الاسم.
- **لو في موجة محاولات فاشلة**: هتظهر تنبيه أحمر في «نظرة عامة»؛ شوف «النشاط» وفلتر بـ «دخول فاشل» لتعرف الـ IP.

## 5) حاجات لازم تبقى عارفها بصراحة
- الدخول بالاسم والكود **ضعيف بطبيعته** (الأسماء مطبوعة في الكشوف). الحماية الفعلية: القفل التصاعدي + التسجيل الكامل + إمكانية الإيقاف + ربط Google. اقرأ `SECURITY.md`.
- الصفحة بتقول للطالب إن بياناته بتتسجّل — راجع سياسة الجامعة بخصوص الـ IP ومدة الاحتفاظ.
- الـ Docker والـ Lighthouse واختبار الجهاز الحقيقي ودخول Google الفعلي **ما اتجرّبوش** هنا (اقرأ قسم Verification في `README.md`).
- المادة الثامنة placeholder لحد ما تحدد اسمها.

## 6) خريطة الكود السريعة
- `server/lib/arabic.js` — تطبيع الأسماء (الهمزات، ى/ي، ة/ه، التشكيل، التطويل، المسافات).
- `server/repo.js` — كل الاستعلامات (الإحصائيات `overview()`/`charts()` بتحسب الأيام بتوقيت القاهرة وبتتعامل مع التوقيت الصيفي).
- `server/routes/admin.js` — SSE (`/stream`)، السجلات + CSV، الطلاب، المحتوى، الرفع (multer + allow-list + SHA-256).
- `client/js/core.js` — `api()` (CSRF تلقائي)، `enter()/countUp()/reveal()` (الأنيميشن مع احترام reduced-motion)، `askForm()` (نافذة النماذج).
- `tests/` — شغّل `npm test` بعد أي تعديل في الـ backend.
